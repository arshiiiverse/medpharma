# Remedy Lane — Online Pharmacy Landing Page

A responsive landing page for a fictional online pharmacy serving Chandigarh, Mohali and Panchkula. It's a concept project designed and built by **Arshdeep Kaur**.

🌐 **Live demo:** https://arshiiiverse.github.io/remedy-lane/

## Features

- **Responsive layout** that works from 360px phones up to wide desktops.
- **Working product filters:** category tabs, header search and a "Find a product" bar (category, brand and name).
- **Add to cart** with a live cart counter, plus a wishlist toggle and toast messages.
- **Original SVG illustrations and product art**, with no stock photos and no image files to load.
- **SEO:** meta description, canonical URL, Open Graph tags and `Pharmacy` structured data (JSON-LD).
- **Accessibility:** skip link, keyboard focus styles, ARIA states on tabs and buttons, and reduced-motion support.
- **Zero dependencies:** plain HTML, CSS and JavaScript in one file, with no frameworks or CDNs.

## Built with

HTML5 · CSS3 (Grid, Flexbox, custom properties) · Vanilla JavaScript · GitHub Pages

## Run locally

Open `index.html` in a browser. There's no build step.

---

*Remedy Lane is not a real pharmacy. Products, prices and reviews are sample data for demonstration.*
